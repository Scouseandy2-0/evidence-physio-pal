# Anatomy inspector build and source record

27 November 2026 · version 2026-11-27.2 · independent anatomical review pending.

## Delivered interaction

Selecting a mesh or either accessible picker updates a docked information panel within the model workbench. Desktop uses a side panel; phone layout stacks the model and a bounded information sheet within one workbench. Only the information body scrolls. The panel can be hidden/reopened; selecting again reopens it. An expanded view uses the viewport, an internal structure picker, background inertness, keyboard focus containment, Escape/exit and cleanup on navigation. No document scroll is requested by selection. These are implemented behaviours; visual/device verification remains open.

## Supplied coverage

46/177 selectable muscle groups have draft origin, insertion, action and nerve-supply notes. 50/242 skeletal source structures map to 25 bone-family draft profiles. Paired bone profiles share main anatomy but preserve each selected source ID/laterality; muscle groups still combine sides and sometimes heads. The count is not a percentage of clinical completeness or reviewed material. Source identity, catalogue-only state and missing reference content are explicit for other selections.

Notes are short original factual summaries of selected main anatomy, not copied textbook tables/figures. They are not exhaustive attachment maps, clinical assessment tools or approved teaching material. No 3D attachment coordinates/pins were inferred from the prose. The two meshes remain separate reference models.

## Accuracy checkpoints

Do not transfer a profile using substring similarity: biceps brachii/femoris, FDS/FDP and ECRL/ECRB are distinct. The biceps femoris note separates the two heads’ nerve supply; quadriceps insertions distinguish quadriceps tendon/patella from the patellar-ligament continuation to tibia. Gluteus minimus uses the anterior/inferior gluteal-line origin, unlike medius. Source discrepancies were not copied blindly: a general upper-limb reference describes FCR adduction and emphasises EDC interphalangeal extension; the delivered notes use radial deviation and chiefly MCP extension, supported by the additional references. QL nerve wording is intentionally broad; root-level variations and detailed branches need specialist review. No numerical diagnostic root map or testing algorithm is included.
